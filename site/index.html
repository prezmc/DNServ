Everything a home network needs

The filtering you'd expect from Pi-hole or AdGuard Home, built for two servers from the start, with nothing to set up outside the browser.

Fast

A two-layer cache, prefetching of popular names, and old answers kept ready if the internet drops.

Blocks ads, trackers and malware

Any hosts file, domain list or AdGuard-style list, with wildcards and regex, plus your own allow and block rules.

Rules per device

Groups like Kids, with their own blocked services, safe search, and schedules for bedtime or homework.

See what's going on

Query log, analytics, response times, and a traffic map from every device through your servers to the services it reaches.

Spots threats

Every lookup is scored against public malware and phishing feeds. See what got through, who reached it, and block it in one click.

Keeps working when a server fails

Run two or more nodes. Settings stay in sync, and any node can take over as leader.

Private

Encrypted DNS to Cloudflare or Quad9, or its own recursive resolver (Unbound), optionally through a VPN.

Safe to run

Two-factor sign-in for every account, admin, power-user and viewer roles, an audit log, encrypted backups, and HTTPS.

No config files

Pull the image, start it, finish setup in the browser. Bring your AdGuard Home setup across in one step.

Up and running in five minutes

Any Linux machine with Docker: a mini PC, a NAS, a Raspberry Pi 4 or a VM.

mkdir -p ~/dnserv && cd ~/dnserv
curl -fsSLO https://raw.githubusercontent.com/prezmc/DNServ/main/docker-compose.yml
echo "TZ=America/Chicago" > .env
docker compose up -d

# the setup code is in the log
docker compose logs | grep setup_code
  1. Open http://<server>:8080Enter the setup code from the log.
  2. Create your accountScan the QR code with any authenticator app.
  3. Pick your blocklists and how lookups leave your networkEncrypted to a provider, or fully recursive.
  4. Point your router's DHCP DNS at the serverDevices switch over as they reconnect.
  5. Add a second server any timeMake a join code on the Cluster page and paste it into the new one.
